## 计算流程

指标继承 ATAS 原生 `DOM`，保留平台盘口计算和绘制。新增代码主要处理独立统计栏与黄线。

### 四栏统计

初始化时用盘口快照建立每个价位的基线，不将快照记成增加。之后收到挂量更新，计算新挂量减旧挂量，将正变化累计为增加、负变化累计为减少。

Net取增加减减少；Stacked取增加；Pulled取减少；Both同时画出两者。每栏拥有自己的重置周期，清零累计时保留当前基线。

### 黄线形成

`ZoneEngine` 按价格区域、买卖侧和距最佳报价的距离档建立观察记录。盘口变化超过绝对与相对过滤门槛后计入统计；最近窗口达到事件数、持续性及相对基线突增条件，才形成盘口活动区域。

另一条路径用真实成交观察攻击方向、成交占比、笔数、持续时间和最大推进。攻击成交较多但价格推进有限时，也能形成观察区域。

### 区域后续状态

`PriceReaction` 记录价格进入、离开后再次进入、攻击成交推进和停顿后的收回。引擎同时匹配成交后同价位补量。

持续越过不利边界且达到时间、笔数和量门槛时，区域失守；无活跃或结构证据超过保留时间时，区域过期。失守、过期区域直接清理。

### 绘图

渲染时读取区域快照，筛选现价上下附近的有效区域，合并兼容的相邻区域，再按活跃时间淡化。黄线延伸到图表右侧，说明置于黄线内部，并避开盘口栏和其他说明。

外观淡化与区域有效期分开判断，淡化不延长区域寿命。显示合并也不合并底层成员各自的生命周期。

## 数据与同步

- 盘口与成交由 ATAS 事件提供，使用本机 UTC 到达时间统计秒数。
- `_zonesGate` 保护引擎和统计状态。
- 250毫秒定时器推进时间、过期和重绘；没有新事件不会凭空产生新证据。
- 盘口过期、价差异常或重新建立快照时，暂停相应判断或重建记录。
- 不能从普通历史K线、OHLC或成交足迹还原历史挂撤单。

## 编译

需要 Windows、.NET 10 SDK 和本机已安装平台的 SDK DLL。

在仓库根目录运行：

```powershell
.\DepthOfMarketBeta\Build.ps1
```

脚本依次使用：

- 普通 ATAS：`C:\Program Files (x86)\ATAS Platform`
- ATAS X：`C:\Program Files\ATAS X`

输出位于 `artifacts/depth-of-market-beta-build/ATAS` 与 `ATASX`。编译不会自动安装或操作平台。

只编译一个平台或自定义 SDK 路径时：

```powershell
dotnet build .\DepthOfMarketBeta\DepthOfMarketBeta.csproj -c Release `
  "-p:AtasDir=C:\你的ATAS安装目录" `
  "-p:OutputPath=../artifacts/local-build/"
```

运行时由平台提供 ATAS/OFT 依赖，不需要把平台 SDK DLL一起分发。
